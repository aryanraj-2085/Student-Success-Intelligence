# Data files

Do not commit institutional/student CSV exports. The supplied cohort file is intentionally excluded from Git because it contains identifying and demographic student data.

To run the dashboard locally, provide an authorized cohort CSV matching the fields used in `backend/analytics.py`, or generate/import data using the scripts documented in the root README. Keep student files local and configure `STUDENT_SUCCESS_DATA_PATH` to their path.

`synthetic-future-outcomes-demo.csv` is artificial demonstration data generated by `python -m backend.synthetic_future_demo`. Its records use `SIM-*` identifiers and are not real student data or validated outcome evidence.
